    {% if current_lang == 'en' %}
  • Two-Stage Scraping Architecture: Decouples the process into 2 independent modules: Multi-tier link structure extraction (Link Crawler) and a detail content download/processing module (Detail Crawler) to optimize performance and resource management.

  • JavaScript Injection & Data Cleaning: Executes raw JS blocks directly in browser sessions to completely strip out DOM noise (ads, nav bars, hidden tracking scripts) before text extraction, ensuring pristine structured outputs.
  • Atomic Write Mechanism: Writes streaming logs to temporary `.tmp` buffers before atomically overwriting the main JSON database, preventing structural corruptions if scripts terminate abruptly.
  • Real-time Sync & API Throttling Optimization: Connects to the Google Sheets API to log progress intervals every 30 seconds. Implements delta matching and `batch_update` requests to strictly respect Google's global Rate Limits.

  • Mô Phỏng Tương Tác & Phân Trang (UI Automation): Tự động hóa hành vi cuộn, click chuyển trang danh mục và trang chương lẻ bằng Selenium, vượt qua các rào cản render động của website.

  • Cơ Chế Ghi File An Toàn (Atomic Write): Áp dụng kỹ thuật ghi dữ liệu qua file trung gian .tmp trước khi đồng bộ vào file JSON chính, ngăn ngừa triệt để tình trạng hỏng cấu trúc file khi script bị ngắt đột ngột.
  • Đồng Bộ Real-time & Tối Ưu Tần Suất API: Tích hợp Google Sheets API để cập nhật tiến độ tự động sau mỗi 30 giây. Sử dụng thuật toán so khớp dữ liệu cũ-mới và thực hiện batch_update nhằm giảm tối đa số lượng request, tránh vượt ngưỡng hạn mức (Rate Limit) của Google.

    {% if current_lang == 'en' %}
  • Cron-like Scheduling: Configures a background real-time tracking daemon loop that automatically triggers the Link Crawler on a fixed day (e.g., Friday) at exactly 00:00. Mutex flags (`last_run_date`) prevent redundant thread executions.
  • Process Monitoring & Orchestration: Employs continuous watchdog scripts (every 10s) using PowerShell (`Get-CimInstance`) to inspect actual operational states of underlying headless Python workers.
  • Race Condition Prevention: To avoid bandwidth and CPU starvation, the system implements mutual exclusion logic. If the Link Crawler updates tree branches, the system kills background processes (`Process Tree Kill`) across all related Python/Chrome instances to free core resources.
  • Self-healing & Retry Engine: Once memory leaks are flushed and links settle, the orchestration script reactivates the Detail Crawler. Execution errors are isolated into localized fallback logs for scoped retries in subsequent loops without causing total system failures.
    • {% else %}
  • Lập Lịch Định Kỳ Kháng Đột Biến (Cron-like Scheduling): Thiết lập script quản lý vòng lặp thời gian thực, tự động kích hoạt Link Crawler định kỳ vào một ngày cố định trong tuần (ví dụ: Thứ Sáu) ngay khi bước qua 00:00. Cơ chế chặn trùng lặp (last_run_date) đảm bảo kịch bản chỉ chạy duy nhất một lần mỗi ngày.
  • Giám Sát & Điều Phối Tiến Trình Theo Thời Gian Thực (Orchestration): Xây dựng kịch bản giám sát liên tục (vòng lặp 10 giây/lần) sử dụng PowerShell (Get-CimInstance) để kiểm tra trạng thái thực tế của các tiến trình Python nền.
  • Giải Quyết Xung Đột Tài Nguyên (Race Condition Prevention): Nhằm tối ưu hóa băng thông và CPU, hệ thống áp dụng logic loại trừ lẫn nhau (Mutual Exclusion).   • Tự Phục Hồi & Kháng Lỗi Hệ Thống (Self-healing & Retry Mechanism): Khi Link Crawler hoàn thành nhiệm vụ và giải phóng bộ nhớ, hệ thống giám sát sẽ tự động kích hoạt lại Detail Crawler để tiếp tục tải nội dung.

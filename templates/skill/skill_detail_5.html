Stage 2
Low-Level Reflection

{% if current_lang == 'en' %}In-depth Technical Analysis & Chart Visualization (LLR){% else %}Phân tích Kỹ thuật chuyên sâu & Đồ thị trực quan (LLR){% endif %}

{% if current_lang == 'en' %} The mplfinance library automatically renders trading session candlestick charts and forwards them to the Gemini Vision API. The module simultaneously calculates core technical indicators: MACD, RSI, KDJ, and Z-Score to convert mathematical signals into visual trend insights. {% else %} Thư viện mplfinance tự động kết xuất đồ thị nến phiên giao dịch và chuyển tiếp sang Gemini Vision API. Stage 3
High-Level Reflection

{% if current_lang == 'en' %}Reflection & Tactical Self-Optimization (HLR){% else %}Phản tỉnh & Tự tối ưu hóa chiến thuật (HLR){% endif %}

{% if current_lang == 'en' %} The AI agent executes a cross-referencing mechanism: comparing past trading decisions with the actual fluctuations of the asset return curve. The agent self-derives lessons regarding "FOMO" phases or late stop-losses to optimize weights for subsequent sessions. {% else %} Tác vụ AI thực hiện cơ chế đối chiếu: So sánh các quyết định giao dịch cũ với biến động thực tế của đường cong lợi nhuận tài sản. Agent tự rút ra bài học kinh nghiệm về các pha "Fomo" hoặc cắt lỗ muộn để tối ưu hóa trọng số cho các phiên kế tiếp. {% endif %}

Stage 4
Decision Making

{% if current_lang == 'en' %}Financial Health Filter & JSON Packaged Command{% else %}Bộ lọc Sức khỏe Tài chính & Ra lệnh Đóng gói JSON{% endif %}

{% if current_lang == 'en' %} Comprehensive synthesis of data from the previous 3 tiers combined with the Abarbanell & Bushee corporate financial risk assessment model. The output is strictly enforced via Structured Outputs JSON containing the action rating [BUY, SELL, HOLD] and detailed reasoning (final_reasoning). {% else %} Tổng hợp toàn diện dữ liệu từ 3 tầng trước phối hợp với mô hình đánh giá rủi ro tài chính doanh nghiệp Abarbanell & Bushee. Đầu ra ép cấu trúc nghiêm ngặt qua Structured Outputs JSON chứa định mức hành động [BUY, SELL, HOLD] và lý do lập luận chi tiết (final_reasoning). {% endif %}
